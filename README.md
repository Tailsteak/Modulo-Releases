# Modulo
Build any document in minutes — from your own library of content.
Modulo is a Windows desktop application that helps teams generate customised Word documents from a single master document. Select the sections you need, click Generate, and get a clean, perfectly formatted document in seconds.

No AI — every word is written by your team
No cloud — all processing happens locally on your machine
No coding — if you can use Word, you can use Modulo

Getting Started

Download the latest release from Releases
Extract and run Modulo.exe
Get a free 30-day trial key at usemodulo.com
